⏱ Premium Countdown Timer

A minimal, full-screen countdown timer with a premium black-and-white design. Built with plain HTML, CSS, and JavaScript — no frameworks, no dependencies.
Features -->
Full-screen display — large, elegant serif digits (Fraunces) on a pure black background
Preset durations — 30 minutes, 1 hour, 10 hours, 24 hours
Custom time input — set any duration in hours, minutes, and seconds
Start / Pause / Reset controls
Adjustable text opacity — live slider to control how bold or subtle the timer appears
Keyboard shortcuts:
Space — Start / Pause
R — Reset
Collapsible control panel — hide the controls for a distraction-free countdown
Fully responsive — works on desktop and mobile
Respects reduced-motion preferences
Demo

Open index.html in any modern browser — no build step or server required.
